# Migration to Yandex Mobile Ads SDK 8

Install the skill with the [`skills`](https://github.com/vercel-labs/skills) CLI:

```bash
npx skills add yandexmobile/skills/ads --skill yandex-mobile-ads-android-migrate-to-8
```

Then ask your agent:

```
Migrate my project to Yandex Mobile Ads SDK 8
```

To install the skill manually, copy the `yandex-mobile-ads-android-migrate-to-8`
folder to your agent's skills directory: `.claude/skills/` for Claude Code,
`.cursor/skills/` for Cursor.
