# Yandex Mobile Ads agent skills

Agent skills that help AI coding assistants integrate the
[Yandex Mobile Ads SDK](https://ads.yandex.com/mobile) into Android and iOS apps.

| Directory | Contents |
| :--- | :--- |
| [`ads`](./ads) | Skills for adding the SDK and ad formats and for migrating from SDK 7.x to 8.x |

Install the skills with the [`skills`](https://github.com/vercel-labs/skills) CLI
in the root of your app project:

```bash
npx skills add yandexmobile/skills/ads
```

See [`ads/README.md`](./ads/README.md) for the list of skills and usage details.
